01 / THE PROBLEM

From points to a term structure

A yield curve maps the maturity of a fixed-income instrument to its yield. Market data rarely provides a quote for every possible maturity, so a model can produce a continuous curve from a finite set of observations.

This study works with 15 tenors, from three months to thirty years. Each observation is a pair $(t_i, y_i)$, where $t_i$ is maturity in years and $y_i$ is the quoted market yield.

02 / THE MODEL

Nelson-Siegel-Svensson

The NSS model combines a long-run level, a slope factor, and two curvature factors:

\[ y(t) = \beta_0 + \beta_1 L_1(t; \tau_1) + \beta_2 L_2(t; \tau_1) + \beta_3 L_3(t; \tau_2) \]

The loading functions are:

\[ L_1(t; \tau_1) = \frac{1-e^{-t/\tau_1}}{t/\tau_1} \]
\[ L_2(t; \tau_1) = \frac{1-e^{-t/\tau_1}}{t/\tau_1} - e^{-t/\tau_1} \]
\[ L_3(t; \tau_2) = \frac{1-e^{-t/\tau_2}}{t/\tau_2} - e^{-t/\tau_2} \]
β0Long-run level
β1Short-term slope
β2, β3Curvature effects
τ1, τ2Decay constants

As \(t\) becomes large, the exponential terms approach zero and the curve approaches \(\beta_0\). This gives the model an interpretable long-end anchor while allowing more than one hump.

03 / THE FIT

Calibration by least squares

For each date, the optimizer starts with a six-parameter initial guess and minimizes the difference between the model and the observed yields:

\[ \mathrm{SSE}(p) = \sum_{i=1}^{n} \left[y(t_i; p)-y_i\right]^2 \]

The fitted vector contains \((\beta_0, \beta_1, \beta_2, \beta_3, \tau_1, \tau_2)\). The same calibrated function can then evaluate an unquoted maturity, such as 9M or 25Y.

IMPLEMENTATIONscipy.optimize.minimizeOne independent fit for each of the five market dates.

04 / THE TOOLS

Interpolation and valuation

Model-based interpolation

For a requested maturity $t^*$, the estimate is simply the calibrated curve evaluated at that point:

ŷ(t*) = y(t*; p̂)

The project uses this to estimate 9M, 3.5Y, 12.5Y, and 25Y across all five dates.

Day-count fractions

Actual-day conventions express elapsed time using a selected denominator:

Act/360 = days / 360
Act/365 = days / 365

The convention changes the year fraction and therefore the accrual or discounting result.

Present valuePV = FV / (1 + r)TThe example discounts EUR 2,430.04 at 5% for five years with annual compounding.

05 / SCOPE AND ASSUMPTIONS

Designed for clarity

This is a focused fixed-income analytics implementation, not a live market-data service. The input rates are hard-coded historical observations, the fit is unweighted, and no parameter bounds are imposed.

A production curve engine could extend this foundation with liquidity weights, constrained optimization, discount-factor fitting, instrument cash flows, and automated data ingestion. Stating these assumptions clearly keeps the analysis reproducible and decision-ready.
